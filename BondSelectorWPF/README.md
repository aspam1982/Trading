# BondSelectorWPF

`BondSelectorWPF` - WPF-приложение для анализа защитной облигационной стратегии "ОФЗ-ИН". Стратегия ориентирована на консервативное размещение средств в облигации федерального займа с индексируемым номиналом, то есть в инфляционный слой портфеля с низким кредитным риском эмитента.

## Аннотация стратегии

Основная идея стратегии - получать умеренную облигационную доходность, связанную с инфляционной индексацией номинала ОФЗ-ИН. Это не агрессивная доходная стратегия, а защитный компонент портфеля, который может быть полезен в периоды повышенной или устойчивой инфляции.

В портфель отбираются выпуски ОФЗ-ИН с достаточной рыночной ликвидностью и подходящим сроком до погашения. При выборе учитываются текущая цена, срок до эффективного погашения, расчетная доходность к погашению, оборот по торгам, proxy-оценка спреда и потенциальный эффект carry/roll-down через 1Y forward total return.

Рынок ОФЗ-ИН узкий: в обращении находится ограниченное число выпусков, а ликвидность отдельных бумаг может быть недостаточной для крупных объемов. Поэтому для автоследования такую стратегию разумнее использовать при небольшом капитале или как вспомогательный компонент более широкой облигационной стратегии.

## Ключевые особенности

- Инструменты: ОФЗ с индексируемым номиналом серии 52.
- Цель: защита капитала от инфляционного обесценения и получение умеренной облигационной доходности.
- Риск-профиль: консервативный по кредитному риску, но с риском низкой ликвидности.
- Ребалансировка: по мере изменения ликвидности, дюрации, цены и привлекательности выпусков.
- Ограничение: стратегия плохо масштабируется при большом капитале из-за узкого рынка ОФЗ-ИН.

## Что делает приложение

1. Берет токен T-Invest из Windows Credential Manager по имени, указанному в поле `T-Invest Token`.
2. Загружает локальную базу рейтингов из `issuer_ratings.json`. Для ОФЗ-ИН кредитный рейтинг эмитента фактически не является главным фильтром, но файл остается частью общего расчетного каркаса.
3. Получает с сайта ЦБ РФ историю ключевой ставки и использует последнюю ставку как базовую доходность денежного рынка.
4. Загружает список доступных облигаций из T-Invest.
5. Выделяет инфляционные ОФЗ по названию/тикеру и проверяет срок до эффективного погашения.
6. Для каждой подходящей бумаги берет дневные свечи за последние 30 дней и использует последние 5 торговых дней для оценки ликвидности и спреда.
7. Загружает будущие купоны, считает YTM через IRR и ожидаемую 1Y forward total return.
8. Считает `Score` с учетом excess return к ключевой ставке, спреда, срока и ликвидности.
9. Распределяет вес между лучшими бумагами с положительным `Score`; если качественных выпусков мало, остаток веса считается размещенным в Money Market.

## Основные файлы

- `MainWindow.xaml` - интерфейс: параметры фильтрации, кнопки запуска и таблица результата.
- `MainWindow.xaml.cs` - сценарий запуска: чтение настроек, загрузка данных, построение кандидатов и вывод результата.
- `Domain.cs` - доменная логика: классификация ОФЗ-ИН, аналитика облигаций, скоринг и аллокация портфеля.
- `issuer_ratings.json` - локальная таблица рейтингов, оставленная для совместимости с более широким облигационным каркасом.

## Важные допущения

- Ликвидность считается только по дневным свечам: средний оборот за последние 5 дней с торгами.
- Спред является proxy-оценкой: медиана `(High - Low) / Close * 100` по тем же 5 свечам.
- Цена для расчетов берется из `Close` последней торговой дневной свечи.
- YTM считается приближенно: будущие купоны плюс номинал, НКД не учитывается.
- 1Y forward total return учитывает купоны в течение года, реинвестирование под ставку денежного рынка и терминальную цену.
- Для ОФЗ-ИН ключевой риск не кредитный, а рыночный: изменение ставок, дюрация, цена входа и недостаточная ликвидность.
- Портфель строится только из бумаг с положительным `Score`; остаток веса считается размещенным в Money Market.
