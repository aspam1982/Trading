# RoboAINewsReader

`RoboAINewsReader` - WPF-проект для экспериментов с AI-анализом рыночных новостей и техническим прогнозированием по свечам. Приложение использует T-Invest API для получения инструментов и свечей, а AI-модели - для анализа новостей или генерации прогноза по OHLCV-истории.

## Основные сценарии

- **MainWindow** - стартовый селектор действия. Отсюда пользователь открывает либо прогноз по новостям, либо прогноз по свечам.
- **NewsForecastWindow** - окно прогноза по RSS-новостям. Позволяет выбрать ChatGPT, DeepSeek или последовательный прогон обоими движками, а также задать количество обрабатываемых новостей.
- **CandleForecasterWindow** - окно технического прогноза. Пользователь выбирает тикер акции из выпадающего списка и запускает расчет кнопкой `Рассчитать`; автоматического расчета при открытии окна нет.
- **ChatGPTNewsAnalyzer** - анализатор новостей на базе OpenAI. Сначала выбирает релевантные инструменты, затем анализирует влияние новости на каждый тикер с учетом свечей.
- **DeepSeekAnalyser** - альтернативная реализация того же двухэтапного анализа через DeepSeek API.
- **CandleForecaster** - низкоуровневый клиент OpenAI для технического прогноза по multi-timeframe свечам.

## Поток данных

1. API-ключи читаются из Windows Credential Manager.
2. T-Invest API предоставляет список инструментов, избранные тикеры и исторические свечи.
3. Для новостного прогноза RSS-новости передаются выбранному AI-анализатору вместе со свечным контекстом релевантных инструментов.
4. Для свечного прогноза локальный кэш `CandleData` дополняется свежими данными только после нажатия `Рассчитать`.
5. Прогнозы сохраняются в файлы `Forecasts_{ticker}_{timeframe}.json`, чтобы не пересчитывать уже обработанные даты.

## Важные ограничения

Проект исследовательский: результаты AI-анализа не являются торговой рекомендацией. Перед использованием сигналов в торговой системе нужно отдельно проверять качество данных, устойчивость prompt-контракта, ошибки API, задержки, стоимость запросов и реалистичность прогнозов на истории.
