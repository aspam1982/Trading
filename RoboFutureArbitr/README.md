# RoboFutureArbitr

`RoboFutureArbitr` - WPF-приложение для исследования и запуска стратегии арбитража между акцией и связанными с ней фьючерсами. Проект использует T-Invest API и классы из `CommonClasses`.

## Режимы запуска

После старта открывается главное окно-селектор:

- **Сбор данных** (`DataCollector`) - подключается к T-Invest, отбирает торгуемые пары акция-фьючерс, подписывается на цены, стаканы, сделки и свечи. Наблюдения сохраняются в `TradesHistory.json`.
- **Анализ данных** (`DataPresenter`) - загружает собранную историю, фильтрует ее по отклонению, комиссии, времени и размеру сделки, а затем строит графики для выбранного фьючерса.
- **Торговый робот** (`RobotTrading`) - создает `RobotFuturesArbitr`, показывает статистику фьючерсов и консоль, дает команды запуска и остановки робота.

## Идея стратегии

Стратегия ищет расхождения между ценой базовой акции и ценой фьючерса на эту акцию. Если отклонение превышает заданные пороги с учетом комиссии и доступной ликвидности, робот рассматривает возможность открытия арбитражной позиции. В настройках учитываются минимальный объем фьючерса, максимальный размер сделки, срок до экспирации, защитный гэп, число свечей для усреднения и дни вокруг дивидендов.

## Основные файлы

- `MainWindow.xaml` - стартовый селектор режимов.
- `DataCollector.xaml.cs` - сбор онлайн-данных и запись истории.
- `DataPresenter.xaml.cs` - анализ сохраненной истории и построение графиков.
- `RobotTrading.xaml` / `MainViewModel.cs` - торговый режим и управление роботом.
- `Analytics.xaml` / `AnalyticsViewModel.cs` - разбор операций и портфеля торгового робота.

## Важное замечание

Торговый режим работает с реальным `RobotFuturesArbitr` и может обращаться к брокерскому API. Перед запуском нужно проверить API-ключ, счет, параметры риска и ограничения размера сделки.
