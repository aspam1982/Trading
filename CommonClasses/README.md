# CommonClasses

`CommonClasses` - общий библиотечный проект для торговых, исследовательских и WPF-проектов решения `Trading`. В нем собраны обертки над T-Invest API, кэш исторических свечей, технические индикаторы, настройки роботов, базовый контракт торгового робота, арбитражный робот и оптимизатор параметров стратегий.

## Основные зоны ответственности

- **Helper.cs** - преобразование типов T-Invest (`Quotation`, `MoneyValue`, `CandleInterval`), расчет гарантийного обеспечения, сопоставление таймфреймов, общие настройки роботов и работа с Windows Credential Manager.
- **HistoricalData.cs** - локальный кэш OHLCV-свечей, догрузка недостающих интервалов через callback, индикаторы MA/EMA/RSI/ATR/Supertrend/Heiken Ashi, модели сделок и стаканов.
- **RobotMovingAverage.cs** - робот по направлению набора EMA для торговли фьючерсом на выбранную акцию.
- **RobotGrokAdvice.cs** - робот RSI/MA: вход по выходу RSI из экстремальных зон с опциональным MA-фильтром.
- **RobotGrokAdvice1.cs** - робот на пересечении fast/slow MA с ATR-фильтром и расчетом защитных уровней.
- **RobotFuturesArbitr.cs** - робот арбитража акция-фьючерс: потоковые подписки, стаканы, сделки, позиции и статистика.
- **TradingRobotOptimizer.cs** - генетический оптимизатор параметров стратегий.
- **Lowess.cs** - LOWESS-сглаживание и инкрементальный EMA-калькулятор.

## Как используется

`CommonClasses` подключается из `RoboTrader`, `RoboFutureArbitr`, `RoboAINewsReader` и `StrategyBacktester`. Проекты верхнего уровня отвечают за UI и сценарии запуска, а общая библиотека хранит бизнес-логику, модели данных, индикаторы и доступ к брокерским данным.

## Важные замечания

- API-ключи не должны храниться в файлах настроек. Для этого используется `WindowsCredentialManager`.
- `HistoricalData` может читать локальный кэш и догружать недостающие свечи через переданный `QueryDataDelegate`.
- Роботы могут выставлять реальные заявки через T-Invest API. Перед запуском нужно проверять настройки счета, тикера, риск-параметры и режим, в котором используется робот.
