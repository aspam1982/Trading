# RoboTrader

`RoboTrader` - WPF-приложение для запуска и наблюдения за торговыми роботами из проекта `CommonClasses`.

Проект не содержит основную торговую математику сам по себе. Он выполняет роль пользовательской оболочки:

- создает выбранный тип робота;
- запускает и останавливает торговый цикл;
- показывает состояние робота, позиции, маржу и консольный вывод;
- открывает окно настроек робота;
- отображает историю изменения депозита и сделки по счету;
- пишет диагностические логи через NLog.

## Основной сценарий

1. При запуске `MainViewModel` читает `RoboTrader.Properties.Settings.Default.RobotType`.
2. По имени типа создается один из доступных роботов:
   - `RobotMovingAverage`;
   - `RobotGrokAdvice`;
   - `RobotGrokAdvice1`.
3. Если в настройках робота включен `AutoStart`, робот запускается сразу.
4. Пользователь может управлять роботом через меню `Robot`: `Start`, `Stop`, `Settings`, `History`.
5. При закрытии главного окна приложение не завершается, а скрывается в трей. Завершение выполняется через команду `Exit`.

## Окна

### MainWindow

Главное окно приложения. Оно привязано к `MainViewModel` и отображает:

- заголовок текущего робота;
- текущий статус;
- консольный вывод;
- список позиций;
- информацию о марже.

### Settings

Окно редактирования настроек конкретного робота. Настройки копируются через сериализацию/десериализацию, поэтому пользователь меняет временную копию. В рабочий робот настройки попадают только после подтверждения.

### DepoHistoryViewer

Окно аналитики по истории депозита. Оно строит два графика:

- динамику депозита;
- свечи целевого инструмента за тот же период.

Также окно загружает операции покупки и продажи по счету через T-Invest API.

## Логи

Логирование настраивается в `MainViewModel`:

- предупреждения и ошибки выводятся в консоль;
- ошибки пишутся в `Errors.log`;
- текущий лог робота пишется в `Robot.log`.

## Важные ограничения

`RoboTrader` работает с реальными объектами `RobotBase`, которые могут подключаться к T-Invest API и выполнять торговые действия в зависимости от настроек робота. Перед запуском нужно проверить API-ключ, тикер, счет, режим работы и параметры риска в настройках выбранного робота.
